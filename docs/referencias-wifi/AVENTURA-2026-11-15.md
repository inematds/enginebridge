# Aventura: serviço contínuo com motor independente

Projeto: `~/projetos/aventurasinemavideo`, commit `5b4301b` publicado no origin.
Configuração comentada: `auto/ia.yaml`. Instruções completas: `auto/README.md` no projeto.

- `producao`: agente completo, assinatura Codex, gpt-6.1-sol, medium; teto de 4 horas/48 GB.
- `classificacao`: visão das fotos, assinatura Codex, gpt-6.1-sol, medium; configuração separada.
- Restauração das imagens: motor Codex assinatura já existente, preservado.
- Publicação: fila e yt-pubx existentes; horários e políticas preservados.

```bash
ia-crons ver aventura
ia-crons configurar aventura producao --tipo assinatura --motor codex --modelo gpt-6.1-sol --esforco high
ia-crons validar aventura
```

O exemplo altera só o esforço de produção; a configuração entregue usa medium.
As alterações valem na próxima chamada, sem reiniciar um episódio em andamento.
API Anthropic/OpenAI/OpenRouter documentadas e desativadas. O agente completo exige CLI com ferramentas;
API de texto/visão não substitui o agente apenas pela troca do nome do motor.

Aprendizado para outros sistemas: inventariar também os serviços contínuos. Distinguir uma execução
interrompida por cota/login/timeout da reprovação editorial: manter a matéria reservada, preservar arquivos,
avisar o monitor e retomar depois. Validar a configuração antes de reservar e passar o resultado pelo portão existente.
